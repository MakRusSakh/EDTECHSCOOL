## 11.1. Обзор приложений

### Матрица приложений

| Приложение | Платформа | Пользователи | Приоритет |
|------------|-----------|--------------|-----------|
| Student Web App | Web (React) | Ученики | Критический |
| Student Mobile | iOS, Android | Ученики | Высокий |
| Parent Web App | Web (React) | Родители | Высокий |
| Parent Mobile | iOS, Android | Родители | Средний |
| Teacher Web App | Web (React) | Учителя, методисты | Высокий |
| Admin Panel | Web (React) | Администраторы | Средний |

### Общие принципы UX

| Принцип | Описание | Реализация |
|---------|----------|------------|
| **Age-appropriate** | Интерфейс адаптирован под возраст | Разные темы для 1-4, 5-8, 9-11 классов |
| **Accessibility** | Доступность для всех | WCAG 2.1 AA, поддержка screen readers |
| **Offline-first** | Работа без интернета | PWA, локальное кэширование |
| **Mobile-first** | Приоритет мобильных | Responsive design |
| **Gamification** | Игровые элементы | Баллы, достижения, streak |
| **Minimal cognitive load** | Минимум отвлечений | Чистый интерфейс, фокус на контенте |

### 11.2.3. Адаптация под возраст

| Элемент | 1-4 класс | 5-8 класс | 9-11 класс |
|---------|-----------|-----------|------------|
| **Визуал** | Яркий, мультяшный | Современный, чистый | Минималистичный |
| **Навигация** | Крупные иконки | Иконки + текст | Текстовое меню |
| **Геймификация** | Максимум (питомцы, истории) | Средняя (достижения) | Минимум (статистика) |
| **Тьютор аватар** | Мультперсонаж | Стилизованный | Абстрактный/текст |
| **Шрифт** | Крупный (18px+) | Средний (16px) | Стандартный (14px) |
| **Сессия** | 15-20 мин | 25-35 мин | 40-50 мин |

### 11.2.4. Состояния и обратная связь

**Состояния загрузки:**

```typescript
interface LoadingStates {
  skeleton: boolean;      // Первичная загрузка
  spinner: boolean;       // Действие в процессе
  progress: number;       // Загрузка контента (0-100)
  streaming: boolean;     // Ответ AI генерируется
}
```

**Обратная связь на ответы:**

| Результат | Визуал | Звук | Анимация |
|-----------|--------|------|----------|
| Правильно | Зелёная галочка ✓ | Позитивный | Конфетти (1-4 кл) |
| Частично | Жёлтый восклицательный | Нейтральный | Пульсация |
| Неправильно | Красный крестик ✗ | Мягкий негативный | Покачивание |
| Streak +1 | Огонь 🔥 | Бонусный | Вспышка |

## 11.5. Mobile Apps

### 11.5.1. Особенности мобильной версии

| Аспект | Решение |
|--------|---------|
| **Офлайн** | Кэширование уроков, синхронизация при подключении |
| **Push** | Напоминания, достижения, сообщения |
| **Камера** | Сканирование рукописных решений |
| **Микрофон** | Голосовой ввод для AI-тьютора |
| **Жесты** | Свайпы для навигации |
| **Виджеты** | Прогресс дня, следующее занятие |

### 11.5.2. Упрощения для мобильной версии

| Функция Web | Мобильная адаптация |
|-------------|---------------------|
| Полный редактор контента | Только просмотр, мелкие правки |
| Детальная аналитика | Сводные показатели |
| Видеоконференции | Упрощённый режим |
| Администрирование | Критичные функции только |

### 11.5.3. Специфичные функции

**Для ученика:**
- Фото решения → OCR → проверка
- Голосовой чат с тьютором
- AR для геометрии (будущее)
- Напоминания по геолокации

**Для родителя:**
- Быстрый просмотр статуса
- Push о важных событиях
- Подтверждение платежей (биометрия)
