## 🎯 Краткое описание проекта

### Миссия

Создать образовательную платформу, которая обеспечивает каждому ученику **персонализированный путь** получения полного среднего образования с качеством, превосходящим традиционные школы.

### Ключевые особенности

- **🤖 AI-First подход** — искусственный интеллект в ядре всех процессов
- **📚 Полная программа 1-11 классов** — соответствие ФГОС
- **🎓 Аттестат государственного образца** — через партнёрство с аккредитованной школой
- **🌍 Готовность к масштабированию** — от РФ до международного рынка

### Целевые показатели (3 года)

| Метрика | Цель |
|---------|------|
| Активных учеников | 50 000 |
| Результаты ЕГЭ | +15% к среднему |
| Retention (год) | >80% |
| NPS родителей | >60 |
