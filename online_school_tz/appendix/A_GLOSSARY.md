## A.1. Образовательные термины

| Термин | Определение |
|--------|-------------|
| **Адаптивное обучение** | Подход к обучению, при котором содержание, темп и формат материала автоматически подстраиваются под индивидуальные особенности ученика |
| **Когнитивный профиль** | Набор характеристик, описывающих особенности восприятия, обработки информации и обучения конкретного ученика |
| **Зона ближайшего развития** | Концепция Выготского: разрыв между тем, что ученик может сделать сам, и тем, что может сделать с помощью |
| **Mastery Level** | Уровень владения концепцией или навыком (обычно 0-1), определяемый на основе истории взаимодействий |
| **Сократический метод** | Педагогический приём, при котором учитель ведёт ученика к пониманию через серию наводящих вопросов |
| **Интервальное повторение** | Метод запоминания, при котором материал повторяется через увеличивающиеся интервалы времени |
| **Формативное оценивание** | Оценивание в процессе обучения для корректировки, а не для выставления итоговой оценки |
| **Суммативное оценивание** | Итоговое оценивание по завершении темы/курса |
| **ФГОС** | Федеральные государственные образовательные стандарты |
| **ОГЭ** | Основной государственный экзамен (9 класс) |
| **ЕГЭ** | Единый государственный экзамен (11 класс) |
| **Remediation** | Процесс устранения пробелов в знаниях |
| **Scaffolding** | Постепенное уменьшение поддержки по мере освоения материала |

## A.2. AI/ML термины

| Термин | Определение |
|--------|-------------|
| **LLM (Large Language Model)** | Большая языковая модель — нейросеть, обученная на больших объёмах текста для генерации и понимания естественного языка |
| **RAG (Retrieval-Augmented Generation)** | Метод, при котором LLM дополняется информацией, извлечённой из базы знаний |
| **IRT (Item Response Theory)** | Математическая модель для оценки сложности заданий и способности учеников |
| **CAT (Computerized Adaptive Testing)** | Адаптивное тестирование, при котором следующий вопрос выбирается на основе предыдущих ответов |
| **NLP (Natural Language Processing)** | Обработка естественного языка — область AI, работающая с текстом и речью |
| **Embedding** | Векторное представление текста/объекта в многомерном пространстве |
| **Fine-tuning** | Дообучение предобученной модели на специфических данных |
| **Prompt Engineering** | Искусство составления запросов к LLM для получения нужного результата |
| **Token** | Единица текста для LLM (примерно 4 символа или 0.75 слова) |
| **Inference** | Процесс получения предсказаний от обученной модели |
| **Feature Store** | Хранилище признаков для ML-моделей |
| **Model Registry** | Система версионирования и хранения ML-моделей |
| **A/B Test** | Эксперимент для сравнения двух вариантов |
| **Uplift** | Прирост метрики в результате изменения |

## A.3. Технические термины

| Термин | Определение |
|--------|-------------|
| **API (Application Programming Interface)** | Программный интерфейс для взаимодействия между системами |
| **REST** | Архитектурный стиль для построения веб-API |
| **gRPC** | Фреймворк для межсервисного взаимодействия на основе Protocol Buffers |
| **JWT (JSON Web Token)** | Стандарт для передачи данных аутентификации |
| **RBAC (Role-Based Access Control)** | Управление доступом на основе ролей |
| **ABAC (Attribute-Based Access Control)** | Управление доступом на основе атрибутов |
| **Микросервисы** | Архитектурный подход, при котором приложение разбивается на независимые сервисы |
| **Kubernetes (K8s)** | Платформа для оркестрации контейнеров |
| **CI/CD** | Непрерывная интеграция / непрерывная доставка |
| **IaC (Infrastructure as Code)** | Управление инфраструктурой через код |
| **CDN (Content Delivery Network)** | Сеть доставки контента для ускорения загрузки |
| **WAF (Web Application Firewall)** | Фаервол для защиты веб-приложений |
| **SSR (Server-Side Rendering)** | Рендеринг страниц на сервере |
| **WebSocket** | Протокол для двустороннего общения в реальном времени |
| **Message Queue** | Очередь сообщений для асинхронного взаимодействия |
| **Event Sourcing** | Паттерн, при котором состояние хранится как последовательность событий |
| **CQRS** | Разделение команд и запросов |
| **Circuit Breaker** | Паттерн защиты от каскадных отказов |

## A.4. Бизнес-термины

| Термин | Определение |
|--------|-------------|
| **NPS (Net Promoter Score)** | Индекс готовности рекомендовать (от -100 до +100) |
| **Retention** | Удержание — доля пользователей, остающихся активными |
| **Churn** | Отток — доля пользователей, прекративших использование |
| **CAC (Customer Acquisition Cost)** | Стоимость привлечения клиента |
| **LTV (Lifetime Value)** | Пожизненная ценность клиента |
| **MRR (Monthly Recurring Revenue)** | Ежемесячная повторяющаяся выручка |
| **ARR (Annual Recurring Revenue)** | Годовая повторяющаяся выручка |
| **Unit Economics** | Экономика единицы — доходы и расходы на одного клиента |
| **B2C** | Business-to-Consumer — продажи конечным потребителям |
| **B2B** | Business-to-Business — продажи бизнесам |
| **B2G** | Business-to-Government — продажи государству |
| **EdTech** | Education Technology — технологии в образовании |
| **K-12** | Kindergarten through 12th grade — дошкольное и школьное образование |
| **MVP (Minimum Viable Product)** | Минимально жизнеспособный продукт |
| **PMF (Product-Market Fit)** | Соответствие продукта рынку |
| **SLA (Service Level Agreement)** | Соглашение об уровне сервиса |
