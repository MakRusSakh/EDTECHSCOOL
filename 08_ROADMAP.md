### 18.2. Детализация по фазам

#### Фаза 1: Foundation (M1-M6)

| Месяц | Спринты | Deliverables |
|-------|---------|--------------|
| M1 | 1-2 | Инфраструктура: Kubernetes, CI/CD, базовые сервисы |
| M2 | 3-4 | Auth Service, User Service, API Gateway |
| M3 | 5-6 | Content Management System, базовый контент |
| M4 | 7-8 | Learning Process, Student Web App (MVP) |
| M5 | 9-10 | LLM Gateway, базовый AI Tutor |
| M6 | 11-12 | Cognitive Profiler, Auto Grader, интеграция |

**Критерии завершения фазы:**
- [ ] 100 тестовых учеников могут пройти полный урок
- [ ] AI-тьютор отвечает с latency < 3 сек
- [ ] Автопроверка тестов работает с accuracy > 99%
- [ ] Базовая диагностика формирует профиль

#### Фаза 2: Core AI (M7-M12)

| Месяц | Спринты | Deliverables |
|-------|---------|--------------|
| M7 | 13-14 | Learning Path Optimizer, Gap Detector |

| M9 | 17-18 | Socratic Engine, Emotion Recognizer |
| M10 | 19-20 | RAG система, мультимодальный ввод |
| M11 | 21-22 | Exercise Generator, Explanation Generator |
| M12 | 23-24 | Essay Analyzer, контент 1-4 классы |

**Критерии завершения фазы:**
- [ ] Персонализация улучшает результаты на 10%+
- [ ] Gap detection с accuracy > 85%
- [ ] Сократический диалог в 70% случаев
- [ ] Генерация заданий с quality score > 0.8

### 19.2. Критический путь

```
Infrastructure → Auth → Content Mgmt → Session Controller → Student App
     │              │          │              │
     └──────────────┼──────────┼──────────────┘
                    │          │
                    ▼          ▼
              LLM Gateway → AI Tutor → Advanced Tutor → Full Platform
```

**Критические зависимости:**
1. Auth Service блокирует все остальные сервисы
2. Content Management блокирует Learning Process
3. LLM Gateway блокирует все AI-компоненты
4. Student App блокирует запуск пилота

## 22. Риски и митигация

### 22.1. Технические риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Зависимость от LLM-провайдеров | Высокая | Высокое | Мультипровайдер, fallback, собственные модели |
| Высокая стоимость LLM | Высокая | Среднее | Кэширование, оптимизация промптов, fine-tuning |
| Latency LLM | Средняя | Высокое | Стриминг, предзагрузка, edge computing |
| Масштабирование | Средняя | Высокое | Архитектура с запасом, нагрузочное тестирование |
| Качество AI | Средняя | Высокое | A/B тесты, human-in-the-loop, мониторинг |

### 22.2. Бизнес-риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Лицензирование | Средняя | Критическое | Партнёрство с аккредитованной школой |
| Конкуренция | Высокая | Среднее | Фокус на AI-дифференциации |
| Привлечение клиентов | Высокая | Высокое | Пробный период, рекомендации, контент-маркетинг |
| Retention | Средняя | Высокое | Геймификация, персонализация, качество |
| Регуляторные изменения | Низкая | Высокое | Мониторинг, гибкая архитектура |

### 22.3. Операционные риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Нехватка ML-специалистов | Высокая | Высокое | Раннее найм, обучение, аутсорс части задач |
| Срыв сроков контента | Средняя | Среднее | Параллельная работа команд, буфер |
| Безопасность данных детей | Низкая | Критическое | Аудит, pentest, compliance |
| Выгорание команды | Средняя | Среднее | Реалистичные сроки, work-life balance |
